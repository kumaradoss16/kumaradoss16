## Which projects should you build first?

Based on your System & Network Engineering career direction, Python/Flask background and local VMware lab, I recommend this sequence.

Phase 1 — Linux Security Baseline Auditor

Beginner–Intermediate

Build a read-only Python CLI that audits SSH, firewall, permissions, users and services, then exports JSON and HTML reports.

Phase 2 — ConfigDrift

Intermediate

Add configuration snapshots, baseline comparison, change classification and regression tests.

Phase 3 — Linux Server Health & Log Monitor

Intermediate

Collect health metrics and logs, define alert thresholds, and generate incident reports.

Phase 4 — BackupProof

Intermediate

Implement backup integrity checks, restore validation, retention policies and recovery evidence.

Phase 5 — Linux Server Operations Manager

Advanced

Combine the proven tools into a multi-server platform with SSH-based collection, role-based access, audit logs and controlled operations.

## Suggested technology stack

| Component             | Recommendation                                                   |
| --------------------- | ---------------------------------------------------------------- |
| Core automation       | Python 3, Bash                                                   |
| System interfaces     | `psutil`, `subprocess`, `systemd`, `/proc`, `/sys`               |
| Remote administration | OpenSSH, optionally Paramiko                                     |
| API                   | Flask or FastAPI                                                 |
| Database              | SQLite initially; PostgreSQL when multi-user features are needed |
| Dashboard             | HTML, CSS and vanilla JavaScript                                 |
| Testing               | pytest, mocked command outputs and disposable Linux VMs          |
| Deployment            | systemd service; Docker where appropriate                        |
| Lab environment       | Ubuntu Server VM + Kali VM in VMware                             |

Important: Build and test against a Linux VM first. Keep the initial tool read-only, use least-privilege access, avoid arbitrary remote command execution, and require explicit approval for changes to firewalls, SSH configuration, accounts or services.

Your best first project is Linux Security Baseline Auditor. It is small enough to complete, directly relevant to system administration and security roles, and can later become a module in your larger Linux Server Operations Manager.
